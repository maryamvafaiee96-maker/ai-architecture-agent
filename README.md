# AI Architecture Agent

**A Persian-language AI assistant for architectural research, design development, and future automation of architectural software.**

## 1. Project Overview

AI Architecture Agent is a project to develop a specialized artificial intelligence assistant for architecture and interior design.

The system is intended to support architectural students and designers through research, design analysis, concept development, design evaluation, and workflow automation.

The project focuses on Persian-language interaction and integration with professional architectural software.

## 2. Main Objectives

- Architectural research and information analysis
- Support for academic projects and thesis development
- Architectural concept generation and design alternatives
- Design review and critical evaluation
- Automation of repetitive architectural tasks
- Direct interaction with architectural software through APIs and automation tools

## 3. Planned Software Integration

The development roadmap includes:

- **AutoCAD 2026:** Drawing, editing, layers, and drafting automation.
- **Revit 2025:** BIM workflows, plans, elevations, sections, schedules, and documentation.
- **3ds Max 2026:** 3D modeling, scene management, materials, lighting, and cameras.

These integrations are planned development goals and are not yet implemented.

## 4. Development Status

The project is currently in its initial development stage.

- Initial project structure created.
- Python development environment configured.
- Basic Python AI core implemented and tested locally.
- Specialist role structure defined.
- API connection and software integrations are planned next steps.

The current GitHub repository is being prepared to document the project and track future development.

## 5. Technology Stack

- Python 3.12
- OpenAI-compatible API architecture
- AutoCAD API and automation tools
- Revit API
- 3ds Max scripting and automation tools

## 6. Planned Development Phases

1. Develop the AI core and API connection.

3. Develop research, analysis, and design-support workflows.
4. Integrate AutoCAD.
5. Integrate Revit.
6. Integrate 3ds Max.
7. Implement testing, validation, and iterative improvement.

## 7. Intended Users

- Architecture students
- Interior designers
- Architects
- Architectural researchers

## 8. Project Vision

The long-term vision is to create a practical architectural AI agent capable of understanding design requirements, interacting with professional software, producing editable architectural outputs, and reviewing its own work with human supervision.
